この地図について

グリーンレーザ（ALB：航空レーザ測深）は、水を通りやすい緑色のレーザを使って、陸と海底の地形をまとめて測る方法です。藻場を壊さずに広い範囲を測れます。この地図では、海底の深さ・傾き・デコボコ（ざらつき）から、藻場ができやすい場所を簡単なルールで2つのタイプに分けました。調べた方法と結果は調査メモにあります。
